# 🏠 House Price Prediction using Linear Regression

## 📌 Overview

This project implements a **Linear Regression** machine learning model to predict house prices based on features such as:

* 📐 Square footage
* 🛏️ Number of bedrooms
* 🛁 Number of bathrooms

The project demonstrates the basic workflow of a supervised machine learning problem, including data preparation, model training, prediction, and evaluation.

## 🛠️ Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* Scikit-learn

## 🤖 Machine Learning Algorithm

**Linear Regression**

Linear Regression is a supervised learning algorithm used to predict a continuous numerical value based on one or more input features.

## 🔄 Project Workflow

1. Load the dataset
2. Explore and preprocess the data
3. Select relevant features
4. Split the data into training and testing sets
5. Train the Linear Regression model
6. Make predictions
7. Evaluate the model

## 🎯 Objective

To build a simple machine learning model that can estimate house prices based on basic property characteristics.

## 🚀 How to Run

1. Clone this repository.
2. Open the Jupyter Notebook.
3. Install the required libraries.
4. Run the notebook cells sequentially.
